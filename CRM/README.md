# CRM - Мини-карточка лида

Простая веб-страница для добавления лидов в CRM систему.

## Функциональность

### Основные возможности:
- ✅ Добавление нового лида с заполнением формы
- ✅ Валидация обязательных полей (имя и телефон)
- ✅ Отображение ошибок при невалидных данных
- ✅ Сохранение лидов в localStorage
- ✅ Отображение списка сохранённых лидов
- ✅ Данные сохраняются после обновления страницы
- ✅ Возможность изменения этапа сделки для каждого лида

### Поля формы:
- Имя клиента (обязательное)
- Номер телефона (обязательное)
- Источник лида: «Холодный» или «Тёплый»
- Ответственный: «Лидоруб» или «МОП»
- Этап сделки: Новый лид / Квалифицирован / Назначена консультация / Отказ
- Переключатель «Запрошено ТЗ»

## Использование

1. Откройте файл `index.html` в браузере
2. Заполните форму добавления лида
3. Нажмите кнопку «Сохранить»
4. Лид появится в списке ниже формы
5. При необходимости измените этап сделки через выпадающий список
6. Данные сохранятся в localStorage и останутся после обновления страницы

## Что проверено и исправлено самостоятельно

1. **Проверка валидации**: Убедился, что обязательные поля (имя и телефон) действительно проверяются перед сохранением
2. **Тестирование localStorage**: Проверил, что данные корректно сохраняются и загружаются из localStorage
3. **Безопасность**: Добавил функцию `escapeHtml()` для экранирования пользовательского ввода и предотвращения XSS атак
4. **Уникальность ID**: Использую `Date.now()` для генерации уникальных идентификаторов лидов
5. **Сортировка**: Лиды сортируются по дате создания (новые сверху)
6. **UX улучшения**:
   - Автоматическая очистка формы после сохранения
   - Уведомления об успешном сохранении и ошибках
   - Автоматическое скрытие сообщений через 5 секунд
7. **Дополнительное задание**: Добавил возможность изменения этапа сделки (кнопка с выпадающим списком в каждой карточке)
