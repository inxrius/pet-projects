# 💰 Finance Tracker API

Серверное приложение для учёта личных доходов и расходов.

## 🚀 Возможности

- Управление пользователями
- Категории доходов / расходов
- Финансовые транзакции с привязкой к категориям
- Получение списка транзакций пользователя
- Валидация данных и строгая обработка ошибок

## 🧱 Стек

| Категория        | Инструменты                                         |
| ---------------- | --------------------------------------------------- |
| Язык             | Go 1.23+                                            |
| Роутер           | [chi](https://github.com/go-chi/chi)                |
| Хранилище        | In‑memory (готово к замене на PostgreSQL)           |
| Контейнеризация  | Docker, Docker Compose                              |
| Линтер           | [golangci-lint](https://golangci-lint.run/)         |
