## Краткий анализ покрытия требований

| ID требования | Требование | Количество тест-кейсов |
| --- | --- | --- |
| T1 | Пользователь может добавить задачу с названием и сроком выполнения. | 2 |
| T2 | Задачи отображаются в списке. | 2 |
| T3 | Задачи можно отмечать как выполненные. | 2 |
| T4 | Выполненные задачи перемещаются в архив. | 2 |
| T5 | Есть фильтр задач: "Все", "Активные", "Выполненные". | 4 |
| T6 | При первом запуске показывается приветственный экран. | 2 |
| T7 | При свайпе влево задача удаляется. | 2 |
| T8 | Поддерживается тёмная тема. | 2 |

## Тест-кейсы

### TC-001 — Добавление задачи
**Требование:** T1
**Приоритет:** Critical
**Тип:** Positive
**Предусловия:** Приложение открыто
**Шаги:**
1. Нажать на кнопку "Добавить задачу"
2. Ввести название задачи и срок выполнения
3. Нажать на кнопку "Сохранить"
**Ожидаемый результат:** Задача добавляется в список
**Статус требования:** Проверено

### TC-002 — Недобавление задачи
**Требование:** T1
**Приоритет:** Critical
**Тип:** Negative
**Предусловия:** Приложение открыто
**Шаги:**
1. Нажать на кнопку "Добавить задачу"
2. Ввести пустое название или пустой срок выполнения
3. Нажать на кнопку "Сохранить"
**Ожидаемый результат:** Сообщение об ошибке выводится
**Статус требования:** Требует уточнения (требование T1)

### TC-003 — Отображение задач
**Требование:** T2
**Приоритет:** High
**Тип:** Positive
**Предусловия:** Приложение открыто, есть задачи в списке
**Шаги:**
1. Открыть список задач
2. Проверить, что все задачи отображаются в списке
**Ожидаемый результат:** Все задачи отображаются в списке
**Статус требования:** Проверено
